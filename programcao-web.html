Programação Web

Esta página reúne os materiais de aula da disciplina de Programação Web.

A disciplina apresenta os princípios do desenvolvimento de aplicações web, desde a comunicação entre navegador e servidor até a construção de sistemas com interfaces dinâmicas e persistência de dados. Serão estudadas soluções arquiteturais, formas de acesso a bases de dados e recursos para proporcionar interatividade às aplicações.

As atividades práticas utilizarão Java com Spring Boot no desenvolvimento do servidor e Thymeleaf na construção de páginas HTML dinâmicas. Ao longo da disciplina, os conceitos serão aplicados em estudos de caso que integram interface, regras de negócio e acesso a dados.

Conteúdos da disciplina​

  • Fundamentos da Web: protocolo HTTP, arquitetura web e características das aplicações web.
  • Programação no cliente: HTML, CSS e JavaScript para estruturar páginas, definir sua apresentação e adicionar interatividade.
  • Programação no servidor: desenvolvimento com Spring Boot, tratamento de requisições e organização da aplicação segundo o padrão MVC (Model–View–Controller).
  • Páginas dinâmicas com Thymeleaf: templates, apresentação de dados e integração de formulários com o servidor.
  • Controle de sessão: manutenção de informações entre requisições e acompanhamento da interação do usuário com a aplicação.
  • Persistência de dados: integração com bancos de dados e operações de cadastro, consulta, atualização e exclusão.
  • Frameworks web e estudos de caso: aplicação dos conteúdos na construção de sistemas com Spring Boot e Thymeleaf.

Referências da disciplina​

  • MELO, A. A. Programação Java para Web. 2. ed. Novatec, 2015.
  • MAGRI, J. A. Programação Web com Plataforma Java – Fundamentos e Desenvolvimento de Aplicações. Érica, 2014.
  • PUREWAL, S. Aprendendo a Desenvolver Aplicações Web. Novatec, 2014.

A bibliografia complementar está disponível na ementa.

Ementa

Materiais de aula​

Os materiais podem ser acessados pelos links abaixo ou pelo menu lateral da disciplina.

Aula 1 — Introdução à Web e ao HTTP​

Conceitos básicos de Web e programação web, comunicação cliente-servidor, requisições e respostas HTTP e introdução ao HTTPS. Inclui slides, vídeos de apoio e uma atividade de observação no navegador.

Ir para o material da Aula 1.

Aula 2 — Introdução ao HTML​

HTML e hipertexto, estrutura básica de um documento, tags essenciais e diferenças entre elementos inline e de bloco. Inclui exemplos e uma atividade de construção de uma página.

Ir para o material da Aula 2.

Aula 3 — HTML: tags, formulários e validação​

Revisão e ampliação das tags HTML, estrutura semântica, tabelas e formulários. Tipos de campos, validação nativa, envio com GET e POST e exemplo completo de cadastro acadêmico, com exercícios de consolidação.

Ir para o material da Aula 3.

Materiais extras​

Configuração do ambiente​

Instalação e configuração de Java e Maven no Windows, extensões e configurações do VS Code, orientações sobre Lombok e MapStruct, uso do Maven Wrapper e verificação de um projeto Spring Boot com Thymeleaf.

Acessar o guia de configuração do ambiente.
